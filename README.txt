FACE GEOMETRY V2 — experimental prototype

Included:
- Existing local face geometry measurements, camera/photo input, text report and print-to-PDF
- Experimental tier names displayed and selectable manually for interface testing
- Free/Premium $20 demo UI
- Email form validation only (NOT real authentication)
- Payment demo UI only (NO payment processing)

IMPORTANT:
Login, verified admin roles, and payment processing are not connected. Do not represent them as live features. A trusted authentication provider/backend and payment provider are needed before accepting users or money. Tier selection is manual and is not inferred from face images.

Deploy on GitHub Pages:
1. Open your repository on GitHub.
2. Open index.html and choose Edit (pencil).
3. Replace its full contents with the included index.html.
4. Commit changes to main.
5. Wait for Pages to rebuild, then refresh the published site.

The image model and runtime load from public CDNs, so first analysis needs internet.
