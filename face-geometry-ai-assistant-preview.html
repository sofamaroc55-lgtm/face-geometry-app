PREVIEW

This is a first functional prototype. It explains geometry measurements and photo quality locally. It does not upload photos or connect to a cloud AI service.

Hi! Ask about face height/width, eye distance, nose width, mouth width, image quality, or privacy. This demo has sample values so you can test the conversation.
Important: this is not a real generative AI model yet. To connect one, the app needs a secure backend that stores the API key outside browser code. This assistant intentionally does not provide attractiveness rankings.
